PostHog has released a Slack app in beta that allows users to tag @PostHog with requests to fix bugs or build features. The bot spins up a sandbox, creates a plan, edits files, runs checks, and opens draft pull requests using product data as context. It follows repository rules and reacts with emojis during the process, enabling non-engineers to trigger engineering work directly from Slack.
